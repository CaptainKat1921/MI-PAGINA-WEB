Habilidades

A lo largo de mi carrera he adquirido una gran variedad de habilidades de las cuales destacan conocimientos básicos de mecánica, electrónica y programación. Al escoger la programación como mi campo de profundización puedo manejar una serie de programas y lenguajes que he aprendido y que puedo aplicar en una serie de casos muy amplia. A continuación se encuentran mis principales conocimientos y habilidades.


HTML & CSS

Tengo experiencia trabajando en proyectos que involucran la creación de páginas web básicas. Mis conocimientos abarcan desde crear páginas sencillas hasta darles formato y diseño con CSS.

Python

Este es el lenguaje de programación donde tengo más experiencia y conocimientos. He trabajado en múltiples proyectos de una amplia variedad como aplicaciones, páginas, análisis de datos, videojuegos y manejo de base de datos.

C, C# & C++

El uso del lenguaje C fue mi prioridad en muchos proyectos de mecatrónica con microcontroladores. C# ha sido mi acompañante en mis proyectos con Unity y C++ para aplicaciones.


SQL

Consultas a base de datos. Operaciones básicas y uso de MySQL como gestor de base de datos son habilidades que he adquirido para el uso y manejo de datos.

Análisis de Datos

Principalmente con Python. El análisis de datos que he aprendido abarca uso de herramientas como Numpy, Pandas, Seaborn, Plotly y técnicas de aprendizaje automático.

Unity

El desarrollo de videojuegos con Unity y C# ha impulsado mi gusto por la creación de contenido para mis proyectos personales.


GIT

Uso de GIT con comandos básicos para control de versiones así como GITHUB como plataforma de gestión en línea.

Paquetería Office

Uso básico de toda la paquetería office como Word, Excel y Teams para proyectos y trabajos.
